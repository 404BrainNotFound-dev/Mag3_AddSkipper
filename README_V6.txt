Mage Adblockkai V6

Setup

1 Extract the zip file
2 Open the project folder
3 Open command prompt in the folder
4 Run pip install -r requirements.txt
5 Start the program with START_GUI_NO_CMD.vbs
6 Use START_GUI_DEBUG.bat only if you need to see errors

Main use

1 Open LDCloud and make all mobile screens visible
2 Open Mage Adblockkai V6
3 On Home select the app profile you want to work on
4 If the app does not exist click New App
5 Open Settings
6 Click Select Mobile Screens
7 Drag around each mobile screen
8 Press Enter to save
9 Click Select Detection Zones
10 Select the area where close buttons usually appear
11 Add Close By Cross
12 Put the cross on the exact center of the close button and click
13 Add Back By Cross if you want inactivity recovery
14 Add App Icon By Cross if you want app launch by icon
15 Go back to Home
16 Click Start
17 Click Stop when finished

App profiles

Each app has its own templates
Close templates are stored per app
Back templates are stored per app
App icon templates are stored per app
The selected Home app controls which templates are used

Template removal

Settings has these buttons
Remove Close Templates
Remove Back Templates
Remove App Icon Templates
Remove All Templates

Reset

Reset Everything deletes all profiles templates regions screenshots and settings
After reset the app returns to default empty setup

Emergency stop

Press Backspace three times quickly to terminate the program

Important folder

DATA BACKUP COPY ME stores all profiles templates regions screenshots and settings
Copy this folder for backup
