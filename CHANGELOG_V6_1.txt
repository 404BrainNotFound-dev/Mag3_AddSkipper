mag3_addskipper V6.1 Changelog

Version
V6.1

Changes

1. Improved click precision

Close template crop size changed to 36 pixels by default.
Back template crop size changed to 44 pixels by default.
This makes the selected X close and back templates smaller and more precise.

2. Added 3 second screen checks

Each enabled screen is now checked for 3 seconds before the engine moves to the next screen.

3. Added repeated close search during each screen check

During the 3 second screen window the tool keeps searching for close X skip and close ad templates.

4. Added start time app icon check

When Start is clicked the selected app profile is loaded.
The tool checks every enabled screen for that app icon first.
If the app icon is visible it is clicked.

5. Kept templates shared across all screens in selected app

The selected app profile has one close template set.
That same template set is searched on every enabled screen.

6. Improved sequential processing

The engine now checks screens in fixed order.
After the last enabled screen it returns to the first enabled screen.

7. Updated default speed settings

Scan delay is now 0.01 seconds.
Click cooldown is now 0.05 seconds.
Max clicks per minute is now 600.

8. Added new settings

Seconds per screen
After close delay
App launch wait

9. Updated GUI title

The GUI now shows mag3_addskipper V6.1.
